# Torti — 요구사항 명세 (v0.1 초안)

> 납땜·전자 조립 작업 중, 손을 쓰지 않고 **음성으로 질문**하면 **책상 위 캠 화면을 보고** AI가 **음성으로 답해주는** Windows 데스크톱 프로그램.

---

## 1. 배경 및 목표

### 1.1 배경
- 납땜·조립 작업 중에는 양손이 바빠서 검색하거나 키보드를 쓰기 어렵다.
- 책상 위에 웹캠(Elgato)이 있으므로, AI가 작업물을 직접 "보고" 답할 수 있다.

### 1.2 목표
- 페달/단축키 한 번 + 음성 질문 → 수 초 내 음성 답변.
- 질문 시점의 작업물 사진을 AI에게 함께 전달.
- 질문·사진·답변을 자동 기록하여 나중에 복기 가능.

### 1.3 비목표 (Non-goals)
- 실시간 연속 영상 감시 및 자동 경고 (비용·지연 문제로 제외).
- 계측기를 대체하는 정밀 판정 (AI 답변은 **참고용**).
- macOS / Linux 지원 (v1 범위 외).

## 2. 사용 시나리오

| # | 상황 | 사용자 발화 예시 | 기대 동작 |
|---|---|---|---|
| S1 | 부품 식별 | "이 저항 몇 옴이야?" | 캡처 → 색띠 판독 → "4.7kΩ로 보입니다. 멀티미터로 확인하세요." |
| S2 | 납땜 품질 확인 | "방금 납땜한 거 괜찮아?" | 캡처 → 브릿지/냉납 여부 코멘트 |
| S3 | 핀배치 질문 | "이 칩 VCC 몇 번 핀이야?" | 프로젝트 데이터시트 참조하여 답변 |
| S4 | 진행 안내 | "다음 단계 뭐야?" | 프로젝트 메모(조립 순서) 기반 답변 |
| S5 | 일반 질문 | "인두 온도 몇 도로 해야 돼?" | 캡처 없이 텍스트만으로 답변 가능 |
| S6 | 복기 | (GUI에서 기록 탭 열기) | 지난 질문/사진/답변 목록 열람 |

## 3. 기능 요구사항

## 5. 기술 스택 (제안)

| 영역 | 선택 | 이유 |
|---|---|---|
| 언어 | Python 3.12 | AI/음성/영상 라이브러리 생태계 |
| GUI | PySide6 (Qt 6) | 네이티브 수준 Windows GUI, 미리보기 위젯·트레이 지원 |
| 카메라 | OpenCV (DirectShow/MSMF 백엔드) | UVC 웹캠 캡처 |
| 오디오 녹음 | sounddevice | 마이크 입력 |
| STT | faster-whisper (로컬) / 클라우드 STT | 한국어 정확도 |
| AI | Anthropic Python SDK (Claude, 이미지 입력) | 비전 + 대화 |
| TTS | Windows 내장 TTS (pyttsx3/WinRT) / 클라우드 TTS | 설치 부담 최소 |
| 전역 단축키 | keyboard 또는 pynput | 포커스 없이 입력 감지 |
| 저장 | SQLite + 이미지 파일 | 단순·로컬 |
| 비밀 저장 | keyring | Windows Credential Manager 연동 |
| 패키징 | PyInstaller (+ Inno Setup) | 단일 실행 파일 |

> 대안: C# WPF/.NET — 배포는 더 깔끔하지만 STT/비전 연동 생태계가 Python 대비 불리. 우선 Python으로 진행.

## 6. 아키텍처 개요

```
┌──────────────────────── GUI (PySide6) ────────────────────────┐
│  [카메라 미리보기 + ROI]   [대화 로그]   [상태표시: 듣는중/생각중/말하는중] │
└───────────────┬───────────────────────────────────────────────┘
                │ signals/slots
┌───────────────▼───────────── Core Pipeline ───────────────────┐
│ HotkeyListener → AudioRecorder → STT → (CameraCapture + ROI)   │
│        → PromptBuilder(프로젝트 컨텍스트) → LLMClient(stream)   │
│        → TTS(문장 단위) → HistoryStore                          │
└───────────────────────────────────────────────────────────────┘
```

- 각 단계는 인터페이스로 분리하여 엔진 교체 가능 (STT/TTS/LLM).
- 무거운 작업(STT, API 호출)은 워커 스레드에서 실행, GUI 블로킹 금지.

### 상태 머신
`IDLE → LISTENING → TRANSCRIBING → THINKING → SPEAKING → IDLE`
(어느 상태에서든 취소 단축키 → IDLE)

## 8. 리스크 및 미결 사항

| 항목 | 내용 | 대응 |
|---|---|---|
| 해상도 한계 | 1080p 전체 화면으로는 IC 각인·소형 SMD 판독 어려움 | ROI 크롭(FR-13), 현미경(FR-14) |
| 판독 오류 | 저항 색띠(조명 색온도), 미세 냉납 오판 | 답변에 확인 방법 안내 (FR-31) |
| 소음 | 흡연기 팬 소음으로 STT 정확도 저하 | 헤드셋/핀마이크 권장, 노이즈 게이트 |
| 전역 단축키 | 일부 라이브러리는 관리자 권한 필요 가능 | M0에서 검증 |
| 로컬 STT 성능 | GPU 없으면 faster-whisper 지연 증가 | 클라우드 STT 옵션 |
| **미결** | 사용 중인 Elgato 모델 / GPU 유무 / 페달 모델 | 사용자 확인 필요 |
